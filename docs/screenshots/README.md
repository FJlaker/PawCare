# Phase 6 REST Client Evidence

Capture the response pane in VS Code REST Client and save the PNGs in this folder before submitting. Keep the request and its HTTP status visible in each image.

Recommended evidence:

- `patients-list.png`: `GET /api/patients` returns `200`.
- `patient-created.png`: valid `POST /api/patients` returns `201`.
- `invalid-patient.png`: invalid `POST /api/patients` returns `400` with field errors.
- `invalid-date-range.png`: reversed `GET /api/visits` dates return `400`.
- `missing-patient-visit.png`: `POST /api/visits` with an unknown patient ID returns `404`.
- `monthly-report.png`: `GET /api/reports/monthly` returns the month series, including zero-count months.

The requests for these cases are in `tests/api.http`. These images are not generated by the application and are not included until captured from the REST Client.
